# Discord AI Reply Bot

A Discord bot that automatically replies to new messages in a channel using Gemini, in casual native-like English with abbreviations (lol, ngl, tbh, fr, idk, gonna, wanna, and more).

## About

Discord AI Reply Bot watches one target channel and answers new messages like a chill friend hanging out in the server. Replies are generated by Google Gemini, kept short (1 to 3 sentences), and attached to the original message with Discord's reply feature. It runs as a self-bot on a Discord user token, so it behaves like a normal account in the channel.

## Features

- Polls the target channel every 5 seconds for new messages
- Context-aware replies generated by Gemini, in casual native-like English
- Automatic fallback to a second Gemini model if the primary model fails
- Anti-spam throttles: 60 second global cooldown and 5 minute per-user cooldown
- Skips its own messages and messages from other bots
- Reply style is fully customizable through a system prompt in the config

## How it works

1. The bot polls the channel's message list on an interval (default 5 seconds)
2. When a new message from another user appears, it is sent to Gemini with the system prompt
3. Gemini's answer is posted back as a reply to that message
4. Cooldowns are checked before every reply, so a busy channel never gets spammed

## Configuration

All settings live in `config.json` (copy `config.example.json` and fill it in):

- `gemini_api_key`: API key from Google AI Studio
- `gemini_model`: primary Gemini model (default `gemini-3-flash-preview`)
- `gemini_model_fallback`: backup model used when the primary fails (default `gemini-3.1-flash-lite`)
- `discord_token`: Discord user token the bot runs on
- `channel_id`: the channel to monitor and reply in
- `poll_interval`: seconds between channel checks (default 5)
- `reply_cooldown_global`: minimum seconds between any two replies (default 60)
- `reply_cooldown_user`: minimum seconds before replying to the same user again (default 300)
- `system_prompt`: instructions that define the reply style

## Setup

1. Install the dependencies:

```bash
pip install requests colorama
```

2. Copy `config.example.json` to `config.json` and fill in your values
3. Run the bot:

```bash
python bot.py
```

Or use `start-bot.sh`, which is idempotent and will not start a duplicate:

```bash
bash start-bot.sh
```

## Notes

- This bot uses a Discord **user token** (self-bot). Discord strictly forbids automation with user tokens, and the account can be banned if detected. Use a spare account, at your own risk
- A Gemini API key is available for free at [Google AI Studio](https://aistudio.google.com/); the free tier is enough for normal use (around 1,500 requests per day)
